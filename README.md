Restaurant Website

A modern, responsive restaurant website built using HTML, CSS, JavaScript, and Bootstrap 5. It features an elegant design and a user-friendly interface.

Live Demo

"View Website" (https://resturant-site-by-owais.netlify.app/)

Features

- Responsive design for mobile, tablet, and desktop
- Modern navigation bar
- Restaurant food menu with multiple categories
- Image carousel
- Food gallery
- Customer reviews section
- Smooth animations and interactive elements

Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- AOS Animation Library


Run Locally

1. Clone this repository:
   
   "git clone https://github.com/OWAIS-GAMER/RESTURANT-SITE.git"

2. Open the project folder.

3. Open "index.html" in your browser.
